# Simulacro HTML
# Ejercicio 1. Escribe código HTML

Escribe el código HTML necesario para realizar las siguientes tareas:

**a)** Escribe las etiquetas `meta` necesarias para:
- Indicar que la codificación de caracteres es UTF-8.
- Indicar que la página debe adaptarse al ancho del dispositivo.
- Proporcionar una descripción de la página: «Blog dedicado a los videojuegos».

**b)** Mostrar una imagen llamada `videojuegos.jpg`, que se encuentra dentro de la carpeta `imagenes`. La imagen debe tener un texto alternativo adecuado.

**c)** Crear una lista no ordenada con los siguientes elementos:
- Minecraft.
- Roblox.
- Fortnite.
- Rocket League.

# Ejercicio 2. Construye una tabla HTML

Escribe el código HTML necesario para crear una tabla con la siguiente información:

| Producto | Precio | Disponibilidad |
|---|---:|---|
| Teclado | 25 € | Disponible |
| Ratón | 15 € | Agotado |
| Monitor | 120 € | Disponible |

**Requisitos:**
- La tabla debe tener como título «Productos informáticos».
- La primera fila debe contener encabezados.
- Utiliza `thead` y `tbody` para organizar la tabla.
