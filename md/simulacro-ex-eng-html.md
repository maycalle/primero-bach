# HTML Practice Test

## Exercise 1. Write HTML code

Write the HTML code needed to perform the following tasks:

**a)** Write the necessary `meta` tags to:
- Specify UTF-8 character encoding.
- Make the webpage adapt to the device's screen width.
- Provide a description of the webpage: "Blog dedicated to video games".

**b)** Display an image named `videojuegos.jpg`, located inside the `imagenes` folder. The image must include appropriate alternative text.

**c)** Create an unordered list with the following items:
- Minecraft.
- Roblox.
- Fortnite.
- Rocket League.

## Exercise 2. Create an HTML table

Write the HTML code needed to create a table with the following information:

| Product | Price | Availability |
|---|---:|---|
| Keyboard | €25 | Available |
| Mouse | €15 | Out of stock |
| Monitor | €120 | Available |

**Requirements:**
- The table must have the caption "Computer Products".
- The first row must contain table headings.
- Use `thead` and `tbody` to organize the table.
